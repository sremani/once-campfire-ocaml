# M4-T3 Action Text implementation and handoff

`lib/rich_text.mli` exposes `parse`, `sanitize`, `render`, `present_message`, `to_plain_text`, `editable_value`, `mentioned_user_ids`, and the database adapter. `render` and `editable_value` accept an optional request Host for Open Graph self-host decisions, with a neutral default when no HTTP request exists. Signed SGIDs resolve through the verified `attachable` purpose; a separate decoded GlobalID resolver supports stale or tampered user signatures without granting verified mentionee status. `db_adapter_with_gid` supplies both converters to message writes and FTS. Conversion errors raise inside the database transaction so a write rolls back. `View_presenter` supplies current users, freshly signs displayed user SGIDs, passes the actual request Host to presentation/editor conversion, and hands sanitized HTML to `Views.trusted_html_of_sanitized`.

The HTML5 parser is the pinned Nokogiri Gumbo fork in `vendor/gumbo`, including its license, provenance, and local patch record. Limits are 16 MiB raw input, 64 MiB native parser allocation, 400 open elements, 400 attributes per element, and eight nested content attachments. Parser failures are explicit `Error` results. The sanitizer drops event handlers, foreign SVG/MathML content, and dangerous URI schemes; CSS is restricted to safe `color`/`background-color` values. Presentation escapes attribute brackets before autolinking serialized HTML, matching the pinned Rust stored-XSS fix. It trims the rendered fragment and handles URL/email links after HTML serialization so entities and unwrapped elements have the same boundaries as Rails. The editor applies bounded HTML5 tree normalization for nested forms and headings where the Gumbo and html5ever fragment trees differ. There is no new OCaml package or system library dependency.

Verification: `dune exec ./test/m4_t3_test.exe` passes nine focused suites, including seeded SGIDs, Open Graph, remote media, all curated autolink vectors, malformed attachment rescue, HTML5 editor trees, CSS/URI/event/foreign-markup policy, 16 MiB and 400-depth/attribute bounds, 80,000 nested tags rejected quickly, and 4,096 autolinks within the scale bound. `dune exec ./test/m4_integration_test.exe` passes five seeded HTTP suites, including create/show/search of rich messages, decoded-GID mention fallback reaching FTS, actual Host suppressing a same-host Open Graph link, signed media, and pinned Rails media headers. `python3 test/m4_t3_compare.py --direct-rust` verifies byte-exact parity for all 658 pinned cases across presentation, plain text, and editor values, plus zero presentation security violations. [The corpus audit](m4-t3-corpus-gaps.md) records the raw Rails divergences, fixed fuzz classes, fixture hash, and Rust oracle reproduction command.
